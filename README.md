# Кофе Тех Центр

Сайт сервисного центра по ремонту и обслуживанию кофейного оборудования в Оренбурге и области.

## Возможности

- адаптивная посадочная страница;
- заявки от частных клиентов и бизнеса;
- серверное сохранение заявок в защищённой папке;
- уведомления в Telegram без передачи имени и телефона в текст сообщения;
- защищённая ссылка для просмотра заявки;
- политика обработки персональных данных;
- ограничение частоты отправки и защита от простых спам-ботов.

## Структура

- `public_html/` — публичная часть сайта;
- `private/` — конфигурация, заявки и служебные данные вне публичной папки;
- `private/config.example.php` — безопасный шаблон настроек без секретов.

## Развёртывание на Beget

1. Загрузите содержимое репозитория в корень сайта так, чтобы `public_html` была публичной папкой.
2. На сервере скопируйте `private/config.example.php` в `private/config.php`.
3. Заполните `private/config.php` непосредственно в файловом менеджере Beget: токен Telegram-бота, Chat ID и реквизиты оператора.
4. Никогда не добавляйте `private/config.php`, `.env`, пароли или токены в GitHub.
5. Убедитесь, что PHP может записывать файлы в `private/leads/` и `private/rate/`.
6. Проверьте форму заявки и страницу `/privacy.php`.

Для работы серверной части нужен PHP 8+, расширения `mbstring` и `curl`. GitHub Pages не исполняет PHP, поэтому для полноценной работы формы используется Beget или другой PHP-хостинг.

## Безопасность

В репозитории нет рабочего токена Telegram, паролей Beget, API-ключей и `.env`. Они исключены правилами `.gitignore` и должны храниться только на сервере.
