# Авито — Кофе Тех Центр

Этот каталог — рабочий контур для ведения Авито по проекту «Кофе Тех Центр».

## Что уже заложено

- единый банк объявлений в `drafts.json`;
- разные офферы под ремонт, вендинг, эквайринг и запчасти;
- географические версии для Оренбурга и области;
- статусы `draft / ready / published / paused`;
- поля для последующего добавления Avito ID, просмотров, контактов и заявок;
- запрет хранения паролей, токенов и Client Secret в GitHub.

## Принцип работы

1. Объявление сначала создаётся как черновик в `drafts.json`.
2. Заголовок и текст адаптируются под конкретную услугу и географию, а не копируются массово один в один.
3. Перед публикацией проверяются актуальная категория, обязательные поля и требования Авито.
4. После подключения официальной автозагрузки/API объявления можно синхронизировать с кабинетом без передачи пароля от аккаунта в код.
5. После публикации в карточке объявления фиксируются `avito_id`, дата публикации и метрики.
6. По статистике меняются оффер, заголовок, первое фото, цена и CTA.

## Официальная автозагрузка

Для массовой работы используем штатную автозагрузку Авито, а не эмуляцию браузера и не хранение логина/пароля.

Полезные официальные страницы Авито:

- шаблоны по категориям: `https://www.avito.ru/autoload/documentation/templates`
- проверка XML: `https://autoload.avito.ru/format/xmlcheck/`

Поля автозагрузки зависят от категории. Поэтому XML-фид не нужно собирать «наугад»: сначала в кабинете/документации выбирается точная категория услуги, затем под неё добавляется генератор.

## Безопасность

Никогда не добавлять в GitHub:

- пароль от Авито;
- cookies браузера;
- `client_secret`;
- access/refresh tokens;
- Telegram token;
- `.env` и локальные конфиги.

Для будущего API-подключения используется `config.example.php`. Рабочий `config.php` должен храниться только на сервере.

## Следующий технический шаг

После получения доступа к официальной автозагрузке/API:

1. определить точную категорию объявлений;
2. взять официальный шаблон полей;
3. заполнить `avito/config.php` на сервере;
4. добавить генератор XML/API-синхронизацию;
5. сначала прогнать 1 тестовое объявление;
6. только после успешной модерации масштабировать объявления по городам и услугам.
