# Самопроверка CODEX AVITO — Кофе Тех Центр

Версия: 1.1-self-audited

## Итог текущего аудита

Тексты и бизнес-правила приведены к единому source of truth. Публикация намеренно заблокирована до проверки реальных фотографий каждого объявления.

## Найденные и исправленные ошибки

1. Неверные AI-изображения Jetinno, Vendista и KitPos — запрещены на уровне политики.
2. JL25 удалена из production-предложения до отдельной первичной верификации.
3. Выезд был ошибочно обещан для домашних/профессиональных кофемашин — теперь field service допускается только для вендингового оборудования/вендинговой точки.
4. Цены 1 490 / 2 000 / 3 500 ₽, которых не было в source of truth, удалены. Используются цены сайта: диагностика 700, домашний ремонт 1 200, профессиональный/вендинговый ремонт 2 500, ТО вендинга 3 000, эквайринг/телеметрия 2 500, выезд по Оренбургу 1 000 ₽.
5. Убраны неподтверждённые маркетинговые заявления: 24/7, без выходных, «запчасти в наличии», фиксированная гарантия, официальный партнёр/сервис, фиксированный срок ремонта.
6. Брендовые Jetinno и Necta/Unicum/Bianchi/Rheavendors вынесены во вторую волну, чтобы не запускать их автоматически вместе с общим вендинговым объявлением без проверки риска дубля/каннибализации.
7. Статус READY_TEXT_IMAGE_REQUIRED признан небезопасным. Теперь объявления имеют BLOCKED_IMAGE_QA и ready_to_publish=false до проверки изображения.
8. Publication Agent больше не может публиковать только по отсутствию статуса IMAGE_REQUIRED: теперь нужны copy_verified=true + image_verified=true + ready_to_publish=true + PASS внутреннего критика + release validator.
9. Добавлен отдельный Technical Verification Agent и Internal Critic / Red Team.
10. Добавлен автоматический статический validator scripts/avito_quality_gate.py.

## Что проверяет Internal Critic перед релизом каждого объявления

- конкретная услуга действительно оказывается;
- цена совпадает с production_manifest.json и сайтом;
- выезд не обещан вне вендинга;
- марка и модель написаны точно;
- фото реально и соответствует заявленной модели;
- чужое официальное фото не выдаётся за собственный кейс;
- нет выдуманных характеристик оборудования;
- нет обещаний наличия запчастей, срока, гарантии или партнёрского статуса без подтверждения;
- заголовок и описание не противоречат друг другу;
- объявление не является смысловым дублем уже активного объявления;
- CTA не требует от клиента лишних действий и просит модель/симптом/фото ошибки там, где это полезно;
- обязательные поля Avito валидны.

## Release gate

Объявление получает READY_TO_PUBLISH только если одновременно:

- copy_verified=true;
- image_verified=true;
- ready_to_publish=true;
- Internal Critic=PASS;
- python3 scripts/avito_quality_gate.py --release = PASS;
- Autoload на стороне Avito активен.

Пока реальные изображения не проверены, production feed должен оставаться безопасно заблокированным.
